# NEXUS AGENDA

## Objetivo
Criar um sistema simples de agendamentos para pequenas empresas e negócios

## Tecnologias planejadas
- Python
- MySQL
- HTML e CSS

## Funcionalidades
- Cadastro de clientes
- Cadastro de serviços
- Criação de agendamentos
- Controle sobre os clientes
- Controle sobre os serviços
- Consulta de agendamentos
- Consulta de clientes
- Consulta de serviços


## Público-Alvo
Barbearias de pequeno porte

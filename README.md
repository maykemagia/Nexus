# NEXUS AGENDA

## Objetivo
Criar um sistema simples de agendamentos para pequenas empresas e negócios

## Tecnologias planejadas
- Python
- MySQL
- HTML e CSS

## Funcionalidades
- Cadastro de clientes
- Cadastro de serviços
- Criação de agendamentos
- Consulta de agendamentos


## Público-Alvo
Barbearias de pequeno porte

## Estrutura do Banco de Dados

 # Tabelas 
- Clientes (id_cliente, nome, telefone)
- Serviços (id_serviço, nome, preço, duração)
- Agendamentos (id_agendamento, id_cliente, id_serviço, data, horario, status)
